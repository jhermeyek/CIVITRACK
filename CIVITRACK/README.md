\# CIVITRACK - Sistema de Trazabilidad en Obras Civiles



\## Evidencia



GA7-220501096-AA2-EV01 – Codificación de módulos del software según requerimientos del proyecto.



\## Descripción



CIVITRACK es un sistema desarrollado en Java que permite gestionar proyectos de obras civiles mediante operaciones CRUD (Crear, Consultar, Actualizar y Eliminar), utilizando conexión a bases de datos MySQL mediante JDBC.



\## Tecnologías utilizadas



\* Java

\* JDBC

\* MySQL Server

\* MySQL Workbench

\* Apache NetBeans

\* Git y GitHub



\## Funcionalidades



\* Registrar proyectos.

\* Consultar proyectos.

\* Actualizar proyectos.

\* Eliminar proyectos.

\* Conexión a base de datos mediante JDBC.
