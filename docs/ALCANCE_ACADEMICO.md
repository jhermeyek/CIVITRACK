# Alcance académico del frontend

El componente desarrollado demuestra:

- Componentización en React.
- JSX.
- Props.
- Hooks (`useState`, `useEffect`, `useMemo`, `useContext`).
- Eventos (`onClick`, `onChange`, `onSubmit`).
- Renderizado de listas y condiciones.
- Formularios controlados.
- Actualización dinámica del estado.
- Diseño responsive.
- Separación por componentes, páginas, datos, contexto y estilos.
- Comentarios sobre lógica relevante.

El backend, autenticación real, almacenamiento permanente y generación real de PDF quedan fuera del alcance de esta evidencia frontend.
